# Interfaces

modules/fireback is a runtime for web applications written in Fireback.
when building fireback-server/main.go, we build it as a product, which includes other things,
and can contain an interface, abac module etc.

Interfaces are not a part of fireback module, but a part of fireback server, which is fireback + some
other commerical production tools.

These are artifacts which are built and place here.
